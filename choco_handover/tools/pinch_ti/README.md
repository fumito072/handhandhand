# pinch_ti — 親指×人差指つまみ(右手)

2026-11-12 に実機(R1_05419 + Revo 2)で作ったもの。**机に置いたチロルチョコを自動で掴んで持ち上げるところまで成功**(教示した位置にあるチョコ)。

ブリッジ(R1 上の `r1_bridge_server.py`、TCP :8891、有線 `192.168.123.164`)へ直接つなぐので `server.py` は不要。
リポジトリのルートで `.venv/bin/python -u choco_handover/tools/pinch_ti/<名前>.py` として実行する。

## 成功した構成

- **ロボット**: スタンドを一番下まで下げ、足を地面に着ける(吊り下げだと腕を伸ばすたびに胴体が揺れ、カメラの画角が約 3cm ずれる)。
- **教示**: `docs/data/teach_feet_down_20261112/teach_hold.json`。チョコを指に持たせてから机へ下ろし、人が手で形を直した状態を記録したもの。
  - 掴んだ姿勢(右腕 5 関節): `[-0.4798, 0.0385, 0.3109, 0.475, 1.1764]`
  - 指の形: 開き `[402, 635, 49, 846, 847, 846]`、掴み `[485, 635, 233, 846, 846, 845]`(中指〜小指は握り込む)
- **掴みの手順**(`grasp_taught.py`): 6cm 上 → 3cm 上 → 掴み姿勢へ下ろす → 人差指を先に閉じ、続いて親指を閉じる → 3cm・6cm 持ち上げて確認。
- **成否の判定**: 持ち上げ後に親指の近接値が 25 万以上、かつ机の上の元の位置にチョコが写っていないこと。
  成功時の実測: 人差指の指腹 2.3N・近接値 161 万、親指の近接値 45 万。

## 起動からの手順

1. R1 でブリッジを起動: `ssh -f unitree@192.168.123.164 'cd ~/choco-handover-bridge && setsid nohup python3 -u r1_bridge_server.py >/tmp/choco_bridge.log 2>&1 < /dev/null &'`
2. `keeper.py` をバックグラウンドで動かす(**必須**。下の「指の保持」を参照)。
3. `setup_after_boot.py`: 制御を入れる → 首を机へ向ける → 手の形を作る → 右手を机の上空へ。
4. チョコが教示位置にあれば `grasp_taught.py 名前`。
5. 別の位置のチョコは `pick_place.py track 名前`(カメラで探して掴む)。
6. 終わるときは、チョコを置いて(`pick_place.py place 0 -0.02`)、観察姿勢 → `[0.35,0.066,-0.40,-0.90,0.0]` → `BACK_DOWN` → `HOME_R` の順に戻す(上げる経路の逆)。

教え直すときは `teach_hold.py`(引数なし: 5 秒後に閉じ始める → 腕が緩む → 机へ下ろして 3 秒止めると固定 → 記録)。
すでに持たせてあれば `held`、すでに机に置いてあれば `held grounded` を付ける。

## 実機で分かったこと(再発しやすいもの)

- **指の保持**: ブリッジは最後のクライアントが切れると指を停止させ、保持力が抜ける。`keeper.py` を動かしておくこと。
- **指モーターの保護**: 指が強く押し戻される(電流 500mA 超)と、その指は曲げる指令に反応しなくなる。開く指令を 1 回送ると復帰する。
- **腕の小さな動き**: 柔らかいゲインのため、数 mm の指令は摩擦で実行されない。目標から 4mm 以上ずれたら入り直す(`grasp_taught.py` の `go`)。空中では実測が指令から 1〜2cm 垂れる。
- **高さ関係**: 教示した手の傾きは、胴体と机の高さ関係が変わると腕で作れなくなる。スタンドや机の高さを変えたら教え直す。
- **ブリッジが約 5 秒固まる**: 腕デーモンが「Bridge heartbeat timeout」で安全保持に入る。`bot.py` はその場で制御を入れ直して続行する。原因は未特定。
- **首**: 電源を入れ直すと首ヨーは +2.0 rad を指す。`setup_after_boot.py` が -0.12 rad へ向ける。ピッチは自重で約 0.63 rad に落ち着く。
- **触覚**: 親指の指腹の力はほとんど出ない。親指は近接値(チョコが横にあると開いた指でも約 13 万、掴むと 40 万前後)で見る。人差指は指腹の力と近接値の両方が使える。
- **検出**: 「机より明るい塊」方式は手の金属反射を拾う。金色の画素を種にする方式で安定した。
- **ステレオ**: 足を着けていれば手とチョコの相対位置を 3mm 程度のばらつきで測れる。ただしチョコが手のすぐ横にあると奥行きが乱れる。

## カメラ追跡での掴み(成功)

`pick_place.py`。観察姿勢(手を右上へ退ける)からチョコの画素を取り、`docs/data/teach_feet_down_20261112/px_map.json` の換算で位置を出して掴む。

- `pick_place.py track 名前`: カメラで探して掴む。2026-11-12 に 3 回試して 3 回成功(持ち上げ後の人差指の力 3〜4N)。
- `pick_place.py cycle DX DY 名前`: 持っているチョコをずらして置く → 画素を記録 → 掴む。換算を作り直すときに使う。
- `pick_place.py place DX DY` / `observe` / `grasp DX DY 名前`。
- 掴みの要点: (1) 着地した状態でカメラを見て、手とチョコの関係が教示時から 3 画素以上ずれていたら 1.5cm 持ち上げて直す(最大 3 回)。(2) 人差指を先に閉じ、親指は電流 240mA まで閉じ込む。(3) 1cm → 3cm → 6cm と段階的に持ち上げる。
- 届く範囲: 教示位置から手前へ 4cm・奥へ 2cm、右へ 6cm・左へ 2cm。
- 換算は成功 4 回分から作った(当てはめ誤差 1mm、1 点抜き検証で 3〜8mm)。点を増やすと精度が上がる。

## 人の手のひらへ渡す(開発中)

`give.py 名前 [待ち秒]`。チョコを持ったまま待ち、開いた手のひら(MediaPipe + ステレオ、既存の `open_palm.py`)を見つけたら真上 7cm へ腕を伸ばし、**もう一度手のひらを確認してから**指を開いて落とす。確認できなければ落とさない。

2026-11-12 時点の状況:
- 手のひらの検出は動く(差し出された手を連続して検出、3D 位置も取れた)。
- **持っているチョコ(自分の手の位置の目印)が検出できていない**。待機姿勢では指に半分隠れ、金色の面積が小さい。ここが次の課題。代案: 順運動学のつまみ点を使い、カメラ座標との一定のずれを 1 回測って補正する。
- 届く範囲が狭い(上の「届く範囲」+ 前へ 10cm・上へ 12cm 程度)。手のひらはロボットの右手の正面〜やや右に出してもらう必要がある。
- 腕を伸ばす動作と最終確認・落下は未試験。
